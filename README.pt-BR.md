# Cloudflare Clef Fast Wrapper

Cliente resiliente e de alta performance para inferência em modelos Cloudflare Workers AI na borda, equipado com disjuntor de circuito (circuit breaker) de três estados, limitador por balde de tokens e retentativas com backoff exponencial.
